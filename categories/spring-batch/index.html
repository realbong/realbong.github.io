spring-batch

  • 상품을 100개씩 읽고 10개씩 커밋하면, DB 연결도 10개마다 닫힐까?

    fetchSize와 청크 크기가 바꾸는 DB 왕복, 커밋 횟수와 커서 연결 수명을 비교한다.

  • 수정 시각이 같은 상품 120개를 100개씩 읽으면, 나머지 20개는?

    수정 시각이 같은 상품을 빠뜨리거나 중복하지 않도록 updated_at과 id를 함께 기억하는 복합 키셋 페이징.

  • 상품 10만 개를 SELECT 한 번으로 읽으면 메모리에 다 올라갈까?

    selectList와 selectCursor의 차이, PostgreSQL JDBC의 fetchSize와 자동 커밋 조건을 상품 CSV 예제로 살펴본다.

  • Spring Batch에서 100개씩 읽는데 왜 뒤로 갈수록 느려질까?

    MyBatisPagingItemReader의 pageSize와 OFFSET을 따라가며 뒤쪽 페이지가 느려지는 이유와 키셋 페이징을 살펴본다.

  • Spring Batch 돌아가게만 말고, 흐름으로 이해하기

    Spring Batch를 기능 목록이 아닌 Job, Step, Chunk의 실행 흐름으로 이해하기 위한 학습 기록
